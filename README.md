# ReactJS Routing - Task 28

## Task 28 - ReactJS Routing using react-router-dom

This project demonstrates navigation between multiple pages in a React application using `react-router-dom`.

## Problem Statement

The task is to implement navigation between different React routes using `react-router-dom`, allowing users to access different sections of the application.

## Routes

The application contains four main routes:

- `/` - Home
- `/dashboard` - Dashboard
- `/login` - Login
- `/signup` - Signup

## Features

- React Router DOM navigation
- Multiple React routes
- Responsive blog-style Home page
- Dashboard page
- Login page
- Signup page
- Navigation without full page refresh
- Responsive layout

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Vite
